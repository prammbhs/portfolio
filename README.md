✔ Modern and clean design

✔ Easy navigation with smooth scrolling
✔ Deployed live for anyone to explore

## 💻 Technologies Used

This portfolio is built using:

* **React** – Component-based UI development
* **Vite** – Fast frontend build tool
* **JavaScript (ES6+)** – Application logic
* **Tailwind CSS** – Utility-first styling
* **shadcn/ui** – Accessible, reusable UI components
* **Cosmic CMS** – Headless CMS for managing project and content data
* **Responsive Design** – Optimized for all screen sizes

## 📦 Installation (for local view)

If you want to run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/prammbhs/portfolio.git
```

2. Navigate to the project folder:

```bash
cd portfolio
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

Your portfolio will open in the browser (usually at `http://localhost:5173`).
